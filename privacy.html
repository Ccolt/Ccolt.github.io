Privacy Policy

Charlie's Assistant Otto — last updated November 5, 2026

This policy describes how Charlie's Assistant Otto ("the assistant") handles information, including data obtained from Google APIs. The assistant is a private, single-user tool operated by its owner for the owner's own use. It is not offered to the public and has exactly one authorized user: the owner of the Google Account that grants it access.

1. Information the assistant accesses

Only after the owner grants consent, and only for the owner's own account, the assistant may access:

  • Gmail — message metadata and content, in order to read, search, label, draft, and send mail on the owner's behalf.
  • Google Calendar — event details and the calendar list, in order to read the schedule and create, modify, or delete events.
  • Google Drive — file names, metadata, and contents, in order to search, read, upload, organize, and share files.
  • Google Sheets — spreadsheet contents, in order to read and update them.
  • Google Docs — document contents, in order to read and update them.
  • Google Contacts — names, email addresses, and phone numbers, in order to address messages and invite event attendees.

2. How information is used

Data is used exclusively to carry out actions the owner requests or schedules — for example, summarizing an inbox, sending a reply, adding a calendar event, or updating a spreadsheet — and to report the result back to the owner. The assistant does not use Google user data for any other purpose.

3. Limited Use disclosure

Charlie's Assistant Otto's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Specifically:

  • Google user data is used only to provide or improve the user-facing features described above.
  • Google user data is not sold, rented, or traded.
  • Google user data is not used for advertising, ad targeting, or building advertising profiles.
  • Google user data is not used to train, tune, or develop machine-learning or artificial-intelligence models.
  • Google user data is not transferred to third parties except as necessary to provide the requested feature, to comply with applicable law, or as part of a merger or acquisition with notice to the user.
  • No humans read Google user data, except with the owner's explicit consent, for security purposes, or where required by law.

4. Storage and retention

The assistant's credentials — an OAuth refresh token and access tokens — are stored on infrastructure controlled solely by the owner. Tokens are encrypted at rest at the operating-system level and are never shared.
Content retrieved from Google is held in memory or in short-lived working storage only for as long as needed to complete the action the owner requested, after which it is deleted. The assistant does not maintain a permanent copy of the owner's mail, calendar, drive, or document contents. Derived summaries and task records may be retained at the owner's direction, and can be deleted by the owner at any time.

5. Sharing

Information is not shared with third parties, except with the infrastructure providers strictly necessary to run the assistant (for example, the language-model and hosting services the owner has configured), and those providers are bound to use it only to deliver that service. No information is published, syndicated, or made available to advertisers or data brokers.

6. Security

Access is limited to a single authorized owner account. Credentials are never committed to source control or transmitted to unauthorized parties. Access can be revoked at any time.

7. Revoking access and deleting data

The owner can revoke the assistant's access at any time at myaccount.google.com/permissions, or by asking the assistant to revoke and delete its stored credentials. Revocation immediately ends all further access. To request deletion of any retained derived data, contact the address below.

8. Changes to this policy

Material changes will be posted on this page with an updated revision date. Continued use of the assistant after a change constitutes acceptance of the revised policy.

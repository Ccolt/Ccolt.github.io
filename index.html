Charlie's Assistant Otto

A private, single-user automation assistant.

Charlie's Assistant Otto is a personal automation assistant operated by its owner for the owner's own use. It is not a commercial product, it is not offered to the public, and it has exactly one user: the owner of the Google Account that authorizes it. No other person can sign in or grant it access.

What it does

The assistant reads and acts on the owner's own Google Workspace data so the owner can delegate routine work: summarizing email, drafting and sending replies, creating calendar events, reading and writing spreadsheets, and organizing files in Drive. It performs these actions on request or on a schedule the owner sets, and it reports the results back to the owner in a private chat.

Google data it accesses

With the owner's explicit consent it requests access to the following scopes, and uses each one only to carry out the actions listed above:

  • gmail.readonly, gmail.modify, gmail.send — read, label, and send the owner's email
  • calendar — read the owner's calendar and create, update, or remove events
  • drive — search, read, upload, organize, and share the owner's files
  • spreadsheets — read and write the owner's Google Sheets
  • documents — read and write the owner's Google Docs
  • contacts.readonly — look up names and addresses to address messages and invitees

Data handling

Google user data is used only to perform the actions the owner requests. It is not sold, not used for advertising, not used to train machine-learning models, and not transferred to any third party except as needed to run the requested action. Full details are in the privacy policy.
